# Sistema de Gestión de Tickets con Clasificación Automática NLP

## Proyecto
Implementación de una plataforma web serverless para la automatización, clasificación e indexación inteligente de incidentes de soporte técnico mediante Procesamiento de Lenguaje Natural (NLP) en la Oficina de Soporte Informático y Telecomunicaciones de la Red Asistencial Pasco - EsSalud.

## Estado
Fase 0 completada: organización, estructura del proyecto, herramientas, repositorio base y control documental.

## Tecnologías definidas
- Frontend: React + TypeScript + Vite
- Estilos: Tailwind CSS
- Backend: Firebase Cloud Functions + Node.js + TypeScript
- Base de datos: Cloud Firestore
- Autenticación: Firebase Authentication
- Archivos: Firebase Storage
- Hosting: Firebase Hosting
- Control de versiones: Git + GitHub
- Gestión ágil: GitHub Projects o Trello
- Diagramas: Draw.io
- Prototipos: Figma
- Pruebas: Vitest, Jest y k6

## Estructura
- `01_DOCUMENTACION`: documentos de análisis, requerimientos, arquitectura y pruebas.
- `02_EVIDENCIAS`: capturas y evidencias organizadas por fase.
- `03_DIAGRAMAS`: archivos fuente y exportaciones de diagramas.
- `04_PROTOTIPOS`: wireframes y mockups.
- `05_CODIGO_FUENTE`: frontend, funciones y configuración Firebase.
- `06_PRUEBAS`: evidencias y scripts de pruebas.
- `07_INFORME_70`: informe de avance.
- `08_PRESENTACION`: material para exposición.
