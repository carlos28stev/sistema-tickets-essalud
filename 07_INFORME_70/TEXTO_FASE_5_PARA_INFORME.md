# Fase 5: Diseño UI/UX y prototipo visual
Se diseñaron nueve pantallas de alta fidelidad para los roles solicitante, técnico y administrador. El diseño establece navegación por roles, componentes reutilizables, semántica visual de estados y prioridades, indicadores SLA y advertencias de protección de datos. El paquete incluye mockups, una galería HTML y documentación para validación.
