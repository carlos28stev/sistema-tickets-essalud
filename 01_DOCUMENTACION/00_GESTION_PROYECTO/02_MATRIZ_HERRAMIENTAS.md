# Matriz de herramientas

| Categoría | Herramienta | Uso |
|---|---|---|
| IDE | Visual Studio Code | Desarrollo frontend y backend |
| Control de versiones | Git | Historial y ramas |
| Repositorio | GitHub | Respaldo y colaboración |
| Gestión ágil | GitHub Projects / Trello | Product Backlog y sprints |
| Frontend | React + TypeScript + Vite | Interfaz web |
| Estilos | Tailwind CSS | Diseño responsive |
| Backend | Firebase Cloud Functions | Lógica serverless |
| Base de datos | Firestore | Persistencia NoSQL |
| Autenticación | Firebase Authentication | Inicio de sesión y sesiones |
| Archivos | Firebase Storage | Evidencias adjuntas |
| Hosting | Firebase Hosting | Publicación web |
| Diagramas | Draw.io | AS-IS, TO-BE y arquitectura |
| UI/UX | Figma | Wireframes y mockups |
| API | Swagger / OpenAPI | Contratos de servicios |
| Pruebas frontend | Vitest | Pruebas unitarias |
| Pruebas backend | Jest | Pruebas unitarias |
| Rendimiento | k6 | Pruebas de carga |
