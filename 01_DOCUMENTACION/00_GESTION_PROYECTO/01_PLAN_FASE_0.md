# Fase 0 — Organización y preparación

## Objetivo
Preparar el entorno, estructura, herramientas, convenciones y repositorio base del proyecto.

## Actividades ejecutadas
1. Creación de estructura documental.
2. Definición de tecnologías.
3. Definición de convenciones de Git.
4. Creación de estructura base del repositorio.
5. Creación de archivos iniciales de configuración.
6. Definición del esquema de evidencias.
7. Elaboración del checklist de cierre.

## Entregables
- Estructura de carpetas.
- README del proyecto.
- `.gitignore`.
- `.env.example`.
- `firebase.json`.
- Reglas iniciales de Firestore.
- Índices iniciales de Firestore.
- Checklist de fase.
- Matriz de herramientas.
- Plantilla de evidencias.
